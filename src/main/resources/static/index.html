🍽️ Gestor de Inventario Gastronómico

API REST para gestión de inventario gastronómico

Versión 1.0.0

📋 Información de la API

  • Base URL: http://localhost:8080/api
  • Formato: JSON
  • Arquitectura: RESTful con arquitectura en capas
  • Base de Datos: H2 (memoria) o MySQL (WampServer)
